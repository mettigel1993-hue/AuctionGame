Spielfeld · Sammel-Icons

Fertige Kategorien werden zu kleinen Icons

Statt für jede fertige Kategorie eine eigene schmale Spalte zu behalten, wird sie zu einem einzigen kleinen Icon. Wer welche Karte zu welchem Preis (und mit wie vielen Punkten) gekauft hat, steht im Tooltip beim Hover. Zwei Varianten, wo diese Icons landen.

1

Sammel-Leiste je Spielerzeile

Die fertigen Kategorien bilden eine eigene, schmale Spalte direkt neben dem Spielernamen — pro Spieler eine Reihe kleiner Icons statt einer Mini-Spalte pro Kategorie. Die Matrix bleibt: Name → Sammlung → aktive Kategorie.

Matrixspalten: 2 statt 1+N  ·  Breite fest, wächst nicht mit Kategorien  ·  Hover: direkt am Icon

2

Sammel-Tafel neben dem Feld

Die Matrix selbst bleibt so schlank wie möglich — nur Name und aktive Kategorie. Alle fertigen Kategorien wandern komplett aus der Tabelle heraus in eine eigene Tafel daneben (spiegelbildlich zur „Wartet"-Tafel): Zeilen = Spieler, Icons = ihre gekauften Karten je fertiger Kategorie.

Matrix: nur 2 Spalten, nie breiter  ·  Tafel wächst mit jeder fertigen Kategorie  ·  Direkter Vergleich aller Spieler auf einen Blick
